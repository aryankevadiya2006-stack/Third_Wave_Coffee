# ☕ Coffee Sales Dashboard | Power BI

A modern and interactive **Power BI dashboard** built to analyze coffee sales performance across countries, states, products, weekdays, and time of day. This project demonstrates data visualization, KPI tracking, and business intelligence techniques using Power BI.

## 📌 Dashboard Overview

The dashboard provides a comprehensive view of sales performance with interactive filters and visuals, helping users identify trends and make data-driven decisions.

### Key KPIs

* **Total Transactions:** 4K
* **Total Sales:** 113K
* **Active Sales Days:** 381
* **Previous Year Sales:** 6K

*Values are taken from the dashboard PDF.*

## 📊 Dashboard Features

* KPI Cards for business performance
* Total Sales by Country
* Total Sales by Coffee Product
* Total Sales by State
* Total Sales by Time of Day
* Total Sales by Weekday
* Interactive slicers for:

  * Year
  * Country
  * Month

These visuals are shown in the uploaded dashboard.
